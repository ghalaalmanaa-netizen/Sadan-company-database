# Sadan-company-database
SQL code that represent Sadan company 
Sadan Company Database

Project Overview

This project is based on a fictional company that was created as part of a graduation project for an Accounting Bootcamp.

All company information used in this project is fictional, including the company name, employee information, job titles, salaries, contact details, and other related data.

Using the fictional company data from the Accounting Bootcamp project, I developed a relational database to organize and manage the company’s employee information using SQL and MySQL.

The database includes employee details such as job titles, departments, hire dates, salaries, phone numbers, and email addresses, along with the relationship between employees and the company.

Purpose

The purpose of this project is to demonstrate practical skills in:

SQL
MySQL
Relational database design
Creating and managing tables
Primary and foreign keys
Data relationships
SQL queries and data analysis
Note: All company and employee data used in this project is entirely fictional and was created for educational and portfolio demonstration purposes.
